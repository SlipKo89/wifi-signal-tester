# Wi-Fi Signal Tester 0.2.4

- Smart connection diagnosis correlates phone/AP RSSI and SNR, CCQ,
  negotiated rates, MikroTik `p-throughput`, gateway ping/loss and router CPU.
- A compact dashboard verdict opens the observed facts, likely causes and
  concrete checks in plain language.
- The diagnosis uses a stable rolling window, ignores isolated metric spikes
  and starts over after the phone moves to another access point.
- Every push to `main` now produces a downloadable APK in GitHub Actions
  Artifacts without requiring a version tag. Tags still publish Releases.

Download `wifi-signal-tester-0.2.4.apk` below and install it on your Android
device (allow installs from unknown sources when prompted).

See [CHANGELOG.md](../blob/main/CHANGELOG.md) for the full history.

# Wi-Fi Signal Tester 0.2.4

- Умная диагностика сопоставляет RSSI и SNR телефона/точки, CCQ, согласованные
  rates, MikroTik `p-throughput`, ping/потери до шлюза и CPU роутера.
- Краткий вердикт на главном экране открывает наблюдаемые факты, вероятные
  причины и конкретные рекомендации понятным языком.
- Диагностика использует устойчивое окно измерений, игнорирует одиночные
  скачки и начинает замер заново после перехода на другую точку доступа.
- Каждый push в `main` теперь создаёт скачиваемый APK в GitHub Actions Artifacts
  без обязательного тега. Теги по-прежнему публикуют Releases.

Скачай `wifi-signal-tester-0.2.4.apk` ниже и установи на Android-устройство
(разреши установку из неизвестных источников, когда телефон спросит).

Полная история изменений — в [CHANGELOG.md](../blob/main/CHANGELOG.md).
