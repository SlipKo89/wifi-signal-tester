# Wi-Fi Signal Tester 0.2.3

- Expanded MikroTik hardening audit: MAC Telnet/WinBox/Ping, Neighbor Discovery,
  Bandwidth Test Server and authentication, DNS, proxy, SOCKS, UPnP, Cloud and
  SSH strong crypto.
- Every applicable hardening finding links to the relevant official MikroTik
  recommendation in the app and in exported PDF reports.
- IPv4 and IPv6 firewall checks report only whether active rules exist; the app
  no longer guesses whether management services are internet-accessible.
- Connected devices use comments from wireless access lists and DHCP leases,
  then DHCP hostnames, so the station list is easier to understand.

Download `wifi-signal-tester-0.2.3.apk` below and install it on your Android
device (allow installs from unknown sources when prompted).

See [CHANGELOG.md](../blob/main/CHANGELOG.md) for the full history.

# Wi-Fi Signal Tester 0.2.3

- Расширен hardening-аудит MikroTik: MAC Telnet/WinBox/Ping, Neighbor Discovery,
  Bandwidth Test Server и авторизация, DNS, proxy, SOCKS, UPnP, Cloud и
  усиленная криптография SSH.
- У каждой применимой проверки есть ссылка на официальную рекомендацию
  MikroTik — в приложении и экспортированном PDF.
- Проверки firewall для IPv4 и IPv6 сообщают только о наличии активных правил;
  приложение больше не гадает о доступности сервисов управления из интернета.
- Устройства подписываются комментариями из wireless access-list и DHCP leases,
  затем hostname, поэтому список подключённых станций стал понятнее.

Скачай `wifi-signal-tester-0.2.3.apk` ниже и установи на Android-устройство
(разреши установку из неизвестных источников, когда телефон спросит).

Полная история изменений — в [CHANGELOG.md](../blob/main/CHANGELOG.md).
