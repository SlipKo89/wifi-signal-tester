# Wi-Fi Signal Tester 0.2.2

- SSH transport for RouterOS 6/7, with reconnect after the app returns from the
  background.
- Audits no longer treat unreadable RouterOS menus as empty configuration.
- The system audit detects services on non-standard ports, shows their actual
  ports and highlights unencrypted FTP, Telnet, HTTP/WebFig and binary API.
- Bilingual usage guide and project links inside the app.
- Least-privilege Android manifest: no permission to change Wi-Fi/network
  settings, and the launcher name is now correctly shown as Wi-Fi Signal Tester.

Download `wifi-signal-tester-0.2.2.apk` below and install it on your Android
device (allow installs from unknown sources when prompted).

See [CHANGELOG.md](../blob/main/CHANGELOG.md) for the full history.

# Wi-Fi Signal Tester 0.2.2

- SSH-транспорт для RouterOS 6/7 с переподключением после возврата приложения
  из фона.
- Аудит больше не принимает недоступные меню RouterOS за пустую конфигурацию.
- Системный аудит видит сервисы на нестандартных портах, показывает фактические
  порты и подсвечивает FTP, Telnet, HTTP/WebFig и бинарный API без шифрования.
- Двуязычная инструкция и ссылки на проект внутри приложения.
- Минимальный Android-манифест: нет разрешений менять Wi-Fi/настройки сети, а
  системное имя теперь правильно отображается как Wi-Fi Signal Tester.

Скачай `wifi-signal-tester-0.2.2.apk` ниже и установи на Android-устройство
(разреши установку из неизвестных источников, когда телефон спросит).

Полная история изменений — в [CHANGELOG.md](../blob/main/CHANGELOG.md).
